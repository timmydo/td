# grep — the option surface, exit statuses and diagnostics.
#
# td-txt-authored (see spec/README): the vendored GNU suites cover the REGEX
# engine and assert only an exit status, so everything about grep as a PROGRAM —
# which lines it prints, how it prefixes them, what it exits with, what it
# refuses — lives here. Goldens were produced by running each case against GNU
# grep 3.11 under LC_ALL=C.

#### a matching pattern selects the line and exits 0
## argv: grep apple
## stdin:
apple
banana
cherry
apple pie
## END
## stdout:
apple
apple pie
## END
## status: 0
