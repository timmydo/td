# sed — the command language, addressing, options and diagnostics.
#
# td-txt-authored (see spec/README): the vendored GNU sed testsuite drives whole
# SCRIPTS through `sed -f`, so it says little about sed as a PROGRAM — options,
# per-command edge cases, exit statuses, in-place rewriting, what it refuses.
# That is what lives here. Goldens were produced by running each case against
# GNU sed 4.9 under LC_ALL=C.
