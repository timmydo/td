# sed — the command language, addressing, options and diagnostics.
#
# td-txt-authored (see spec/README): the vendored GNU sed testsuite drives whole
# SCRIPTS through `sed -f`, so it says little about sed as a PROGRAM — options,
# per-command edge cases, exit statuses, in-place rewriting, what it refuses.
# That is what lives here. Goldens were produced by running each case against
# GNU sed 4.9 under LC_ALL=C.

# `\`` and `\'` are BUFFER anchors: `M` does not move them, which is the whole
# point of having them alongside `^`/`$`. Separator confinement DOES move them,
# because GNU then matches inside one segment and that segment's ends are the
# buffer's as far as the match can see -- the same asymmetry `\W` has.

#### M does not move the buffer anchor backtick
## argv: sed -n -e N;s/\\`a/X/Mgp
## stdin-json: "a\na\n"
## stdout-json: "X\na\n"
## stderr-json: ""
## status: 0

#### nor without M
## argv: sed -n -e N;s/\\`a/X/gp
## stdin-json: "a\na\n"
## stdout-json: "X\na\n"
## stderr-json: ""
## status: 0

#### while ^ under M does move, which is the difference

## stdin-json: "a\na\n"
## stdout-json: "X\nX\n"
## stderr-json: ""

#### the end buffer anchor is the same

#### while $ under M moves
